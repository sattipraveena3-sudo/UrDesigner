# Development roadmap

## Milestone 1 — private working beta (implemented)

Manual 2D layers and tools; procedural 3D preview; live front/back texture mapping; color/material settings; cloud saves and conflicts; portable exports/imports; backend BYOK connections and text assistance; reviewed constrained AI edits with undo; maker notes; written Academy; dark/light UI. Tests and private publication accompany the source.

## Milestone 2 — public identity and reliability

Configure and verify Google/GitHub OIDC; account lifecycle and profile settings; production session adapter; secure email provider if email login is enabled; stronger upload processing; transactional quotas; asset cleanup; observability, accessibility/browser/device QA, backups and documented key rotation. Recheck provider/hosting terms, costs and limits. Publish publicly only after these gates.

## Milestone 3 — richer creative studio

Validated garment asset library, vector path nodes, multi-selection, alignment/snap, warp, real embroidery motifs, sleeve/collar/pocket components, undo grouping, indexed offline drafts, actual browser performance measurements, configurable work panels, SVG export with sanitization, version browsing/restore and improved preview realism.

## Milestone 4 — AI capabilities and local access

Provider capability discovery and live adapter testing; optional image generation through suitable user accounts; image segmentation and assisted template matching with uncertainty; prompt/model usage transparency; streaming and cancellation; safe paired Ollama/LM Studio companion; operator-approved custom-provider egress service. Support Together, Fireworks, Azure and other providers through adapters without putting keys in the browser.

## Milestone 5 — portfolios, free marketplace and community

Publications separated from private project records, immutable licensed templates, portfolios, collections, followers, likes, comments, feeds, reporting, moderation, admin workflows and basic design challenges. Add original/licensed Academy videos and tutorials. Ship free downloads before sales.

## Milestone 6 — tailoring and physical simulation

Pattern-piece graph, seam relationships, physical units, validated measurements, fabric parameters, cloth solver research and worker/GPU compute options. Pilot with professional pattern makers. Add printable cutting layouts, sewing instructions and fabric/BOM estimates only when verified against actual patterns. Maintain confidence labels and human review.

## Milestone 7 — collaboration and commerce

Versioned collaboration protocol, conflict handling, permissions, shared teams; then payment/entitlement adapters, seller onboarding, refunds, payouts and licensing. Rendering farms and large-scale AI services remain optional paid infrastructure, not requirements for the manual editor.

These are dependency-ordered milestones, not delivery promises. A realistic schedule needs an agreed team, production budget and reviewed acceptance criteria. The long-term Canva + Figma + Blender + CLO3D vision requires sustained specialist engineering, design and garment-domain validation.
